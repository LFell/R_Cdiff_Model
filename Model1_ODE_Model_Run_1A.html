Model 1 ODE Run

Introduction

This script runs the ODE model for Model 1, which simulates the transmission dynamics of a healthcare-associated pathogen within a hospital setting. The model tracks the flow of patients through various states of colonisation and infection, as well as the impact of testing and isolation practices on case detection and missed cases.

This script uses the ODE function defined in “Model1_ODE_Functions.R” and the parameter sets defined in “Model1_ODE_Parameters.R” to run multiple scenarios (S1-S4) and generates outputs including time series of model states and flows, annual summaries, stabilisation assessments, and final cumulative outcomes. The outputs are saved as CSV files in a labelled subdirectory of Outputs/ and key results are also presented in tables and plots.

The model compartments are:
- S (Susceptible): Not colonised or infected
- C (Colonised): Carrying the pathogen but not infected
- I (Infected): Showing symptoms caused by the pathogen
- Xtest (Suspected cases): Isolated or on a general ward, awaiting test result
- FN (False negatives): Symptomatic patients with a false negative result, not isolated, awaiting re-testing
- Xtreat (Confirmed cases): Isolated and receiving treatment, awaiting recovery and discharge
- D: Dead: cumulative count of deaths (absorbing state)

The control variables for scenarios are:
- isolate_before_test: Whether patients are isolated while awaiting test results (TRUE/FALSE)
- prop_I_suspected: Proportion of infected patients identified as suspected cases
- test_sens: Sensitivity of the diagnostic test
- t_test_turnaround: Time in days between test administration and result availability

1) Initial setup

Load libraries, set options, and create an output directory for this run.

rm(list = setdiff(ls(), "params"))

library(scales)

2) Source parameters and functions

Source the ODE functions and parameter sets for the model. The functions include the ODE system definition, scenario running function, and various post-processing functions for summarising and plotting results. The parameters script defines the fixed model parameters (e.g., transmission rates, recovery rates) and the make_mod_parms() function used to build scenario parameter lists in section 3.

source("Scripts/Model1_ODE_Functions.R")
source("Scripts/Model1_ODE_Parameters.R")

4) Model settings

Set the total model run time and time step for the ODE solver. Validate that the settings are appropriate (e.g., time step is positive and less than model time). Create a sequence of time points for the model output.

run_settings <- list(
  model_time = 365 * 5,
  time_step  = 0.5
)
validate_run_settings(run_settings$model_time, run_settings$time_step)
model_time <- run_settings$model_time
time_step  <- run_settings$time_step
mod.t      <- seq(0, model_time, by = time_step)

5) Initial conditions

Set the initial conditions for the model states (S, C, I, Xtest, FN, Xtreat, D) at time 0. These values represent the starting point of the simulation and can be adjusted as needed for different scenarios or sensitivity analyses.

S0      <- 909
C0      <- 86
I0      <- 5
Xtest0  <- 0
FN0     <- 0
Xtreat0 <- 0
D0      <- 0
mod.init <- c(
  S      = S0,
  C      = C0,
  I      = I0,
  Xtest  = Xtest0,
  FN     = FN0,
  Xtreat = Xtreat0,
  D      = D0
)

6) Run scenarios

Run the ODE model for each scenario using the run_scenario function, which takes the scenario parameters and returns a data frame of model states and flows over time. Then, post-process the raw model output to add flow quantities (e.g., cumulative cases, missed cases) using the add_flow_quantities function. Finally, save the post-processed outputs as CSV files in the output directory.

# Run the ODE model

scenario_raw  <- lapply(scenario_parms, run_scenario)

# Post-process the raw model output to add flow quantities (e.g., cumulative cases, missed cases)
scenario_post <- Map(
  f = function(df, parms)
    df %>% add_quantities(time_step = time_step),
  df = scenario_raw,
  parms = scenario_parms
)

# Save the post-processed outputs as CSV files in the output directory

walk2(scenario_post,
      names(scenario_post),
      ~ write_csv(.x, file.path(
        output_dir, paste0("solution_", .y, ".csv")
      )))

7) Negative values checks

Check for any negative values in the model states or flows, which may indicate numerical issues with the ODE solver or problems with the model structure. The negative_value_rows function identifies rows in the data frame where any state or flow has a negative value. Save these rows as separate CSV files for each scenario for further investigation.

neg_tables <- lapply(scenario_post, negative_value_rows)

walk2(neg_tables, names(neg_tables), ~ write_csv(.x, file.path(
  output_dir, paste0("negative_rows_", .y, ".csv")
)))

8) Stabilisation summary

Identify the day on which each model state and flow stabilises for each scenario using the stabilisation_summary function. This function determines when the values of states and flows reach a steady state (i.e., change by less than a certain threshold over a specified number of days). Combine the stabilisation summaries for all scenarios into a single data frame, save it as a CSV, and display it in a table format.

stability_all <- bind_rows(
  stabilisation_summary(scenario_post$S1, "S1"),
  stabilisation_summary(scenario_post$S2, "S2"),
  stabilisation_summary(scenario_post$S3, "S3"),
  stabilisation_summary(scenario_post$S4, "S4")
)
